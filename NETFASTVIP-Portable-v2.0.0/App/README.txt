راهنمای NETFASTVIP — نسخه پورتابل
=====================================

۱) نصب لازم نیست
   کل پوشه را یک‌جا نگه دارید و NETFASTVIP.exe را اجرا کنید.
   مهم: اگر فایل ZIP دانلود کرده‌اید، اول کل آن را Extract کنید و بعد اجرا کنید؛
   اجرای مستقیم از داخل ZIP باعث می‌شود تنظیمات ذخیره نشود.

۲) دسترسی ادمین
   برنامه برای کارهای شبکه (اتصال VPN، نصب گواهی، تعویض DNS) به دسترسی ادمین نیاز دارد؛
   پنجره UAC ویندوز را تأیید کنید.

۳) پروتکل‌ها
   - L2TP / PPTP / SSTP / IKEv2: به هیچ نصب اضافه‌ای نیاز ندارند (از خود ویندوز استفاده می‌شود).
   - OpenVPN: فقط برای اتصال‌های نوع openvpn باید برنامه OpenVPN روی سیستم نصب باشد:
     https://openvpn.net/community-downloads/
     (نسخه Windows 64-bit MSI را نصب کنید — تنظیم خاصی لازم ندارد)
     اگر OpenVPN نصب نباشد، بقیه پروتکل‌ها عادی کار می‌کنند و فقط اتصال‌های openvpn برقرار نمی‌شوند.
     حالت پورتابل (بدون نصب OpenVPN): اگر پوشه‌ای به نام openvpn کنار برنامه باشد شامل:
       - openvpn.exe و همه DLLهای کنارش (کپی از C:\Program Files\OpenVPN\bin یک سیستم نصب‌شده)
       - زیرپوشه driver شامل فایل‌های درایور ovpn-dco (ovpn-dco.inf / .cat / .sys)
     آن‌وقت هیچ نصبی لازم نیست — برنامه بار اول خودش درایور را بی‌صدا نصب می‌کند.

۴) گواهی امنیتی (SSTP / IKEv2)
   بار اول که از SSTP یا IKEv2 استفاده کنید، برنامه با اجازه خودتان گواهی امنیتی را نصب می‌کند.

۵) شخصی‌سازی (config.json)
   فایل config.json کنار برنامه را می‌توانید با Notepad باز کنید و این‌ها را تغییر دهید:
   - "AppName": نام نمایشی برنامه (عنوان پنجره‌ها، تری و میان‌بر)
   - "AppVersion": نسخه نمایشی در پنجره درباره (خالی = خودکار)
   - "TelegramUrl" / "PanelUrl" / "SupportUrl": لینک کانال، پنل کاربری و پشتیبانی

۶) پشتیبانی
   تلگرام: https://t.me/nfv_sup
   
   
   ==============================================
 اگر آنتی‌ویروس یا ویندوز دیفندر برنامه را حذف کرد
==============================================

بعضی از آنتی‌ویروس‌ها (به‌خصوص ویندوز دیفندر) به‌خاطر این‌که NETFASTVIP یک برنامه پورتابل و کم‌شناخته است، ممکن است آن را به‌اشتباه به‌عنوان تهدید تشخیص بدن (False Positive) و فایلش را حذف/قرنطینه کنن. برنامه هیچ کد مخربی ندارد؛ برای رفع این مشکل، پوشه‌ی برنامه را از لیست استثنا (Exclusion) آنتی‌ویروس خودتان اضافه کنید.

---- روش ۱: از تنظیمات ویندوز دیفندر (ساده‌ترین روش) ----
1. کلید Windows را بزنید و «Windows Security» را باز کنید.
2. به بخش «Virus & threat protection» بروید.
3. روی «Manage settings» (زیر Virus & threat protection settings) کلیک کنید.
4. پایین صفحه، روی «Add or remove exclusions» کلیک کنید.
5. روی «Add an exclusion» بزنید و «Folder» را انتخاب کنید.
6. پوشه‌ی NETFASTVIP (همان پوشه‌ای که NETFASTVIP.exe داخلش هست) را انتخاب کنید.

---- روش ۲: با PowerShell (کاربران پیشرفته) ----
روی دکمه استارت راست‌کلیک کنید، «Windows Terminal (Admin)» یا «PowerShell (Admin)» را انتخاب کنید و این دستور را بزنید (مسیر را با محل واقعی پوشه‌ی برنامه‌ی خودتان جایگزین کنید):

    Add-MpPreference -ExclusionPath "C:\Path\To\NETFASTVIP"

این دستور فقط با دسترسی Admin کار می‌کند.

---- اگر از آنتی‌ویروس دیگری (غیر از دیفندر) استفاده می‌کنید ----
در تنظیمات آنتی‌ویروستان بخشی به اسم Exclusions / Whitelist / Trusted Files پیدا کنید و پوشه‌ی NETFASTVIP یا فایل NETFASTVIP.exe را به آن اضافه کنید (نام دقیق این بخش در هر آنتی‌ویروس فرق دارد، معمولاً در تنظیمات Real-time Protection یا Scan Settings است).
